# OrbitNestLab · Spoolman Reorder Upgrade

Experimentelle Beta für eine Spoolman-v2-Nachbestellansicht.

[Installation und Bedienung](spoolman_reorder/README.md)

Der Code ist ein Teststand. Er ersetzt keine bestehende Spoolman-App.
Die generischen Änderungen sind als reviewbarer Patch gegen den
gleichen Spoolman-Commit wie die vorhandene Installation enthalten.
Der Bambu-EU-Provider-Katalog bleibt ein optionales Datenpaket.

Der Bambu-Direktwarenkorb ist derzeit deaktiviert. Produktlinks und
Bestandsregeln sind testbar. Dies ist keine offizielle Spoolman-Version.
